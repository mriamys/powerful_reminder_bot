# Powerful Reminder Bot

Мощный Telegram-бот для управления задачами и напоминаниями, написанный на Python с использованием `aiogram` 3.x, `aiosqlite` и `APScheduler`.

## Особенности
- Современный интерфейс на основе inline-клавиатур (без Web App, всё работает прямо в чате)
- Добавление разовых и ежедневных задач
- Установка точного времени напоминания
- Отметка о выполнении в один клик
- Автоматический сброс ежедневных задач в полночь

## Установка и запуск
1. Склонируйте репозиторий.
2. Создайте виртуальное окружение: `python -m venv venv`
3. Активируйте: `venv\Scripts\activate` (Windows)
4. Установите зависимости: `pip install -r requirements.txt`
5. Скопируйте `.env.example` в `.env` и впишите токен бота от @BotFather.
6. Запустите: `python bot.py`
