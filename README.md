# Powerful Reminder Bot ⏰

Telegram-бот для удобного управления задачами и напоминаниями прямо в чате с интерактивным интерфейсом.

## Возможности

- **Разовые и ежедневные задачи**: создание напоминаний на конкретное время и дату либо повторяющихся каждый день.
- **Inline-управление**: переключение статусов, редактирование и удаление задач в один клик без перехода в сторонние Web App.
- **Автоматический сброс**: ежедневные задачи автоматически переводятся в статус «не выполнено» в полночь.
- **Надёжная доставка**: планировщик напоминаний на базе APScheduler.

## Стек технологий

- Python 3.11+
- aiogram 3.x
- aiosqlite
- APScheduler
- Docker Compose

## Установка и запуск

### Запуск через Docker Compose

1. Создайте `.env` файл на основе настроек:
   ```env
   BOT_TOKEN=ваш_токен_бота
   ADMIN_ID=ваш_telegram_id
   ```

2. Запустите контейнер:
   ```bash
   docker compose up -d --build
   ```

### Локальный запуск

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python bot.py
```
